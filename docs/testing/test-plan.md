# HabitFlow Test Plan — Phase 02I Preparation

**Status:** Test cases drafted; not executed.

## Critical journeys
1. First launch → choose local-only → permissions optional → Today.
2. Create, complete, skip and edit a habit; inspect history and streak.
3. Create a task with due date, recurrence, and subtasks; edit and delete safely.
4. Calendar selection and project board keyboard alternatives.
5. Create goal/milestone; journal entry; focus session; wellness log.
6. Finance income, expense, transfer, reversal, budget and savings; verify balance invariant and integer minor units.
7. Open form, edit, cancel → discard confirmation → focus restored; test unchanged cancel.
8. Offline operations, retry, sync conflicts, account linking, export and deletion.
9. Accessibility: TalkBack, VoiceOver, keyboard, 200%+ text, reduced motion, contrast, visual-only alerts.
10. Responsive compact/medium/expanded widths, landscape, safe areas and keyboard insets.

## Severity
P0: data integrity/security/accessibility blockers; P1: major task failure; P2: usability inconsistency; P3: cosmetic.

## Exit gates
All P0 closed; critical P1 resolved; 54 screen contracts reconciled; representative devices tested; financial invariants covered; privacy/security review documented. No pass claims until evidence is collected.
