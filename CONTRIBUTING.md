# Contributing to HabitFlow

HabitFlow is currently in its **design-only** phase. Please do not add Flutter scaffolding, install scripts, Firebase credentials, or production claims without explicit project approval.

## Contribution workflow
1. Open an issue describing the change, screen IDs, and acceptance criteria.
2. Keep documentation changes focused and link affected requirements.
3. Use a feature branch and a pull request for review.
4. Explain accessibility, offline behavior, privacy, and test impacts.
5. Never commit personal information, tokens, financial exports, or secrets.

## Writing and accessibility
Use clear English, meaningful headings, descriptive labels, keyboard-friendly patterns, text alternatives for charts, and no audio-only requirements.

## Definition of done for a design change
Updated screen/flow specification, component states, error and offline behavior, accessibility considerations, and review/test cases. No design is considered device-validated until actually tested.
